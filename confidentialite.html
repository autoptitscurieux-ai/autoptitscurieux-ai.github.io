Règles de confidentialité de Claude AUTO

Dernière mise à jour : 17 octobre 2026

Claude AUTO est une application personnelle utilisée uniquement par son propriétaire pour publier ses propres vidéos sur ses propres comptes YouTube, Instagram et TikTok.

Données utilisées

L'application utilise uniquement les autorisations accordées par le propriétaire des comptes : envoyer des vidéos et lire les informations de base de ses chaînes (nom de la chaîne). Elle ne collecte aucune donnée sur d'autres personnes.

Stockage

Les jetons d'accès sont stockés uniquement sur l'ordinateur personnel du propriétaire. Aucune donnée n'est vendue, partagée ou transmise à des tiers.

Services Google

L'utilisation des données reçues des API Google respecte les Règles d'utilisation des données utilisateur des services API Google, y compris les exigences d'utilisation limitée. L'application utilise les services API YouTube ; voir aussi les Règles de confidentialité de Google.

Révocation

L'accès peut être retiré à tout moment depuis myaccount.google.com/permissions.
